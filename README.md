# Factorio-Emporio

A random and eclectic collection of Factorio blueprints.

This repository is where I hold my blueprints for various styles of building including spaghetti, city block, chunk-aligned blocks, and free-form. The aim of this repository is to help keep track of changes and allow reverting to a known-good blueprint when I mess things up.

Where I have borrowed designs from other players I have included a console with a heart icon that lists the URL where you can find the original whether that be a YouTube video, a factoriobin share, or a blog page.
